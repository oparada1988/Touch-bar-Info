# Touch Bar Info Plugin for StreamController

A custom StreamController plugin designed to test and showcase full-canvas Touch Bar actions on the Stream Deck +.

## Features
- **Full-Canvas Touch Bar Display**: Utilizes the full 800x100 resolution of the Stream Deck + Touch Bar.
- **Stacked Date & Time**:
  - **Top Line (Date)**: Displayed in a smaller, soft-accent font (e.g. `Mon. Day, Year`).
  - **Bottom Line (Time)**: Displayed in a larger, bold font.
- **Configuration Options**:
  - Toggle between 12-hour (AM/PM) and 24-hour clock formats.
  - Option to show or hide seconds.
  - Choice of date formatting styles.
- **Multi-Input Compatibility**: Supports Touchscreen (`sd-plus`), Dials, and Keys.
